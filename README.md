# VibeDesktop

A native macOS window layout app, made for a calmer desktop. Previously **Proper Mac Tiler**.

**[Download the latest VibeDesktop release](https://github.com/NitsuaFox/VibeDesktop-Releases/releases/latest)**

Choose the **VibeDesktop DMG** in the release assets. Open it, drag **VibeDesktop** onto **Applications**, then open the installed app from Applications and eject the installer disk. Requires macOS 13 or later; supports Apple silicon and Intel.

## Make room for your work

- Pick a layout, then drag a window anywhere into a section to snap it into place.
- Customize layouts visually: split a column, move dividers, merge sections and save your own arrangement.
- Set your preferred spacing, place several windows together and undo a placement.
- Keep the widget nearby, use keyboard shortcuts and optionally launch at login.
- Get an in-app notification when a signed update is available.

## First launch

VibeDesktop needs **Accessibility** access to move and resize windows. Use the app's **Open Accessibility Settings** button, add the installed app and enable it. Window titles and layout preferences stay on your Mac.

Current builds are locally signed and are not Apple-notarized. A new build can require removing the old Accessibility entry and adding the installed VibeDesktop app again, then quitting and reopening it.

## Moving from Proper Mac Tiler

Use **Check for Updates** in your existing app. Your saved layouts and settings carry across to VibeDesktop. The old update address remains available as a migration bridge.

## About this repository

This repository contains **public downloads, release notes and the signed update feed**. Application source is private. GitHub's automatically generated “Source code” archives contain this downloads repository, not the app; use the **VibeDesktop DMG** instead. The ZIP remains available for the in-app updater.

Sparkle verifies the feed and update archives before installation. Third-party license notices are included in the app.
